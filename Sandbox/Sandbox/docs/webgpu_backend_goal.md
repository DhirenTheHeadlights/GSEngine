# Goal: The WebGPU backend lights the scene the same as the native backends

## Aim
The WebGPU backend must render the lighting parity scene to match the native reference, as judged by `Tools/lighting_parity_harness.py`, without changing native output. Keep going across as many tasks as it takes.

## Pass criteria
These are the five criteria `Tools/lighting_parity_harness.py` already judges:
1. Native backends are clean, each produces one hash, and the raster hash equals the ray-traced hash (DX12 reference `0x350203be5257f128`, unchanged by the PCG cloud hash; reference frames `Tools/parity_reports/pcg/20261103_030944/dx12_raster_run*.png`).
2. WebGPU is clean.
3. The WebGPU hash equals the reference.
4. The WebGPU frame is within tolerance: mean difference ≤ 0.5 and ≤ 0.25% of pixels differing by more than 8.
5. All of the above hold on 3 consecutive runs.

## Charter (no need to ask)
- Edit the WebGPU backend, WebGPU-only shader and codegen paths, and the parity tools (including adding a repeatable `--setting KEY=VALUE` to the harness).
- Build, run the harness, and run ablations (GI off, ambient off, baseline) as often as needed.

**Off limits without asking:** any change to native backend output, edits to `settings.ini`, commits.
